# House Configurator

Browser-based 3D house configurator (React, Three.js, Zustand). UI comes from [`@lastch1ld/ui`](https://github.com/lastch1ld/ui), shared with other lastch1ld apps.

```bash
npm install   # needs access to github.com/lastch1ld/ui (git dependency, built on install)
npm run dev   # http://localhost:5173
npm test
npm run build
```
